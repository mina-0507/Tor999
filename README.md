# ЗАДАНИЕ 1
## Условие задания: Замыкание, определяющее нахождение аргуметов в допустимых диапазонах.

1.  Программа создает внешнюю функцию с именем make_checker, предназначенную для создания других функций.
2.  Внутри make_checker определяется внутренняя функция checker, которая содержит логику проверки вхождения числа в диапазон.
3.  Внутренняя функция checker использует переменные min_val и max_val, которые были переданы внешней функции, хотя сами эти переменные не объявлены внутри checker.
4.  Выполнение кода внутри checker пока не происходит — функция только создается и компилируется.
5.  Команда return checker завершает работу внешней функции и возвращает внутреннюю функцию в качестве результата.
6.  Возвращаемая функция checker сохраняет доступ к тем значениям min_val и max_val, с которыми была вызвана внешняя функция (это называется замыканием).
7.  В результате переменная, которой присвоят вызов make_checker, получит готовую функцию с уже зафиксированными внутри границами диапазона.

# ЗАДАНИЕ 2
## Условие задания: Декоратор, который будет оборачивать каждую функцию в try блок для обработки ошибок.

1.  Программа создает функцию-декоратор с именем catcher, которая принимает другую функцию (func) в качестве аргумента.
2.  Внутри catcher определяется внутренняя функция wrapper, которая может принимать любое количество позиционных и именованных аргументов благодаря записи *args, **kwargs.
3.  Внутри wrapper находится блок try-except, который пытается выполнить исходную функцию func с переданными аргументами.
4.  Если при выполнении func возникает любое исключение (Exception), программа перехватывает его и выводит сообщение "Ошибка:" с описанием ошибки, после чего функция завершается без возврата значения.
5.  Функция catcher возвращает созданную функцию wrapper в качестве результата, при этом wrapper сохраняет доступ к исходной функции func.
6.  Программа создает обычную функцию div, которая принимает два аргумента (a и b) и возвращает результат их деления.

# ЗАДАНИЕ 3
## Условие задания: Примените декоратор к замыканию.

1.  Программа создает функцию catcher, которая принимает другую функцию func и возвращает wrapper.
2.  Внутри catcher определяется функция wrapper, которая умеет принимать любые аргументы (*args, **kwargs) и содержит блок try-except для перехвата ошибок.
3.  Блок try внутри wrapper пытается вызвать исходную функцию func с переданными аргументами и вернуть её результат.
4.  Если при вызове func возникает исключение, блок except перехватывает ошибку и выводит в консоль сообщение "Ошибка:" с описанием исключения.
5.  Функция catcher возвращает созданную обёртку wrapper, при этом wrapper сохраняет доступ к исходной функции func через замыкание.
6.  Программа создает функцию make_checker, которая принимает два аргумента: min_val и max_val.
7.  Внутри make_checker определяется внутренняя функция checker, которая принимает один аргумент x и проверяет, входит ли он в диапазон между min_val и max_val.
8.  Если x находится в диапазоне, checker выводит сообщение "{x} подходит" и возвращает True.
9.  Если x находится вне диапазона, checker выводит сообщение "{x} не подходит" и возвращает False.
10. Функция make_checker возвращает созданную внутреннюю функцию checker, которая сохраняет доступ к переданным значениям min_val и max_val через замыкание.
